# Portfolio

Astro portfolio with a horizontal editorial folio for The Intern. Use pnpm.

```sh
pnpm install
pnpm dev
pnpm build
pnpm astro check
```

## Assets

- `src/assets/portrait.png`: The Intern portrait.
- `src/assets/pegaxus-screen.png` and `src/assets/meetly-screen.png`: THE WORK screenshots.
- `src/assets/projects/educonnect/`: EduConnect case-study images.
- `src/assets/logo.png`: portfolio logo.
- `public/favicon-ring.png`: favicon and Open Graph image.
- `public/demos/educonnect.html`: standalone EduConnect demo, also used in the folio preview.
- `public/demos/assets/teacher.jpg`: local teacher avatar for the EduConnect demo. Student names use initials.

Design colors and fonts are documented in `DESIGN.md`. Edit folio copy in `src/data/internFolio.ts`.
